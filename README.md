# 🛋️ AfrikaMeuble

**AfrikaMeuble** est une plateforme e-commerce de meubles haut de gamme fabriqués au Bénin.  
Le site propose des meubles artisanaux de qualité premium avec un design moderne, local et durable.

## 🚀 Fonctionnalités

- Navigation par catégories de meubles
- Connexion / inscription des utilisateurs
- Ajout au panier
- Page de présentation "Qui sommes-nous"
- Interface moderne avec Tailwind CSS & DaisyUI

## 📦 Installation locale

1. Clonez ce dépôt :
```bash
git clone https://github.com/ton-utilisateur/afrika-meuble.git
cd afrika-meuble

2. Créez un environnement virtuel :

```bash
python -m venv env
source env/bin/activate  # Linux/Mac
env\Scripts\activate     # Windows

3. Installez les dépendances :

```bash
pip install -r requirements.txt

4. Lancer le serveur

```bash
python manage.py runserver
